The category summary above the content grid of the page module. It is rendered by `Backend\PageCategorySummaryRenderer` for a page type an extension claims, and an installation replaces it through page TSconfig: templates.fgtclb/category-types.my-site = my-vendor/my-site:Resources/Private/Backend which is looked up as `Resources/Private/Backend/Templates/PageCategorySummary.html` of that package. `rows` carries one entry per registered type of the group, in registry order and including the types the page has no category of. Each entry has the resolved `title` and `iconIdentifier` the markup below uses, and the `type` itself for an override that needs more than those two.
{row.title}
  • A hidden category keeps its place in the list and trades its type icon for the core hidden overlay - an editor has to see that it is assigned and switched off, which is the one thing the page properties do not show. {category.title}
